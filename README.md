# Tulva

Implementation of **Tulva: Practical Asynchronous Threshold FHE**, by Valerio Cini, Antonio Guimarães, Russell W. F. Lai, Michał Osadnik and Ivy K. Y. Woo, to appear at the 48th IEEE Symposium on Security and Privacy (S&P 2027).

The implementation will be made public in this repository by the time the S&P 2027 proceedings are published.
